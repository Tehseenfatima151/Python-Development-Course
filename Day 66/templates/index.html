☕ Cafe & Wifi REST API

A simple RESTful API for browsing and managing cafe data. All responses are returned as JSON.

MethodEndpointDescription
GET/randomReturns one random cafe
GET/allReturns all cafes
GET/search?loc=LondonReturns cafes matching a location
POST/addAdds a new cafe (form data)
PATCH/update-price/<id>?new_price=£3.50Updates a cafe's coffee price
DELETE/report-closed/<id>?api-key=TopSecretAPIKeyDeletes a cafe (requires API key)
