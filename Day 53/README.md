## 🚀 Capstone Project

On Day 53, I built a **Data Entry Job Automation** project using Python and Selenium.

The goal of this project was to automate a repetitive data-entry workflow by collecting information from a website and entering that information into another web-based form.

This project combined several concepts I had learned throughout the Python Development Pro Bootcamp, especially **web scraping, Selenium, browser automation, data processing, and form interaction**.

---

## 🎯 Project Objective

The main objective was to automate the process of:

1. Opening a source website.
2. Collecting required data.
3. Extracting and processing the information.
4. Opening an online form.
5. Automatically entering the collected data.
6. Submitting the form.
7. Repeating the process for multiple records.

Instead of manually entering each record, Python performs the repetitive tasks automatically.

## 🧠 Concepts I Practiced

### 1. Web Scraping

I used Python to extract useful information from web pages.

### 2. Selenium WebDriver

Selenium allowed the Python program to control the browser and interact with web elements.

### 3. Finding Elements

I practiced locating elements using:

```python
By.ID
By.NAME
By.CLASS_NAME
By.CSS_SELECTOR
By.XPATH
```

### 4. WebDriverWait

I used explicit waits to make the automation more reliable when dealing with dynamically loaded web pages.

### 5. Form Automation

The project automatically entered scraped information into form fields and submitted the form.

### 6. Loops

Loops were used to process multiple records without manually repeating the same actions.

### 7. Exception Handling

`try-except` was used to handle possible errors during browser automation.

## 📦 Installation

Install the required libraries:

```bash
pip install selenium
pip install beautifulsoup4
pip install requests
```

Or install everything using:

```bash
pip install -r requirements.txt
```

## ▶️ How to Run

Clone or download the project and open the folder in VS Code.

Then run:

```bash
python main.py
```

The Selenium WebDriver will open the browser and start performing the automated workflow.
