## 🐶 TinDog Project

**TinDog** is a fictional platform designed for dog owners to find suitable companions for their dogs.

The project focuses mainly on creating the **frontend user interface** using HTML, CSS, and Bootstrap.

---

## 🎯 Project Objectives

The main objectives of the TinDog project were to:

* Build a complete responsive website
* Practice HTML structure
* Improve CSS styling skills
* Learn Bootstrap
* Use Bootstrap's responsive grid system
* Create reusable UI components
* Design attractive sections
* Make the website responsive on different screen sizes

## 📱 Responsive Design

One of the major concepts of Day 58 was **responsive web design**.

The website should work properly on:

* 💻 Desktop
* 💻 Laptop
* 📱 Mobile
* 📲 Tablet

Bootstrap's grid system makes it easier to create layouts that automatically adjust to different screen sizes.

---

## 🧩 Bootstrap Grid System

I practiced using Bootstrap's grid system to organize content.

Example:

```html
<div class="row">

    <div class="col-lg-4">
        Content
    </div>

    <div class="col-lg-4">
        Content
    </div>

    <div class="col-lg-4">
        Content
    </div>

</div>
```

The columns automatically adjust based on the screen size.
