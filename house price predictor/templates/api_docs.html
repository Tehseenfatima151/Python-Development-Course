Developer Integration Docs

PropVal.AI REST API

Programmatically calculate property valuations in PKR using our serialized machine learning inference pipeline.

Primary Endpoint

Predict Property Price

POST /api/predict

Request Parameters

Parameter Type Required Validation Bounds / Values
sqft Number / Float Required Min: 100 sqft, Max: 25,000 sqft
bedrooms Integer Required Min: 1, Max: 15
bathrooms Integer Required Min: 1, Max: 15
location String Required Islamabad, Lahore, Karachi, Rawalpindi, Peshawar, Faisalabad, Multan, Gujranwala
Sample JSON Request Body 
{
  "sqft": 1800,
  "bedrooms": 3,
  "bathrooms": 2,
  "location": "Lahore"
}
Sample JSON Response (200 OK) 
{
  "success": true,
  "predicted_price": 18500000.0,
  "formatted_price": "PKR 18,500,000",
  "formatted_crore": "PKR 1.85 Crore",
  "currency": "PKR",
  "price_per_sqft": 10277.78,
  "model": "{{ best_model }}",
  "r2_score": {{ r2_raw }}
}
cURL Example Command 
curl -X POST http://localhost:5000/api/predict \
  -H "Content-Type: application/json" \
  -d '{"sqft": 1800, "bedrooms": 3, "bathrooms": 2, "location": "Lahore"}'
