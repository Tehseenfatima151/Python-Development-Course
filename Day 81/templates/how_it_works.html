How PropVal.AI Works

Discover the end-to-end data processing, feature transformation, and Random Forest machine learning pipeline behind our property valuations.

01
Step 1 — Input Collection

Property Specification Entry

The user specifies the property location (e.g., Lahore, Islamabad, Karachi), covered area in native Pakistani units (Marla, Kanal) or Square Feet, bedroom count, and bathroom count.

02
Step 2 — Data Preprocessing

Scikit-Learn ColumnTransformer

Numerical features (sqft, bedrooms, bathrooms) are scaled via StandardScaler. Categorical city locations are transformed using OneHotEncoder(handle_unknown='ignore') inside a unified Scikit-learn Pipeline.

03
Step 3 — Machine Learning Regressor

Random Forest Ensemble Inference

We benchmark multiple algorithms (Linear Regression vs. Random Forest). Random Forest Regressor achieves superior accuracy (R² ≈ 98.5%) by capturing non-linear relationships between plot area, city tier premiums, and room configurations.

04
Step 4 — Flask Pipeline Execution

Sub-Second Serialization via Joblib

The entire trained pipeline is saved as models/house_price_model.joblib. The Flask server loads this serialized pipeline into memory once on startup to perform instant inference in < 0.5 seconds per request.

05
Step 5 — Pakistani Currency Output

PKR & Crore Denomination Reporting

The raw numerical prediction is converted into standard comma-separated PKR (PKR 18,500,000) and Pakistani financial format (PKR 1.85 Crore or Lacs).
