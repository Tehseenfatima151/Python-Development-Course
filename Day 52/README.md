## 🤖 Project: Instagram Follower Bot

On Day 52, I learned how to use **Selenium WebDriver** to automate interactions with Instagram.

The main goal of this project was to create an **Instagram Follower Bot** that can open Instagram, log into an account, navigate to a target profile, find followers, and automatically interact with the follower list.

This project helped me understand how browser automation can be used to perform repetitive web-based tasks using Python.

---

## 🎯 Project Features

The Instagram Follower Bot demonstrates how to:

1. Open Instagram using Selenium.
2. Log into an Instagram account.
3. Navigate to a target profile.
4. Open the followers list.
5. Scroll through the followers dialog.
6. Locate follow buttons.
7. Automatically click available follow buttons.
8. Handle dynamically loaded content.
9. Use explicit waits instead of relying only on fixed delays.
10. Handle common Selenium exceptions.

## 📦 Installation

Install Selenium:

```bash
pip install selenium
```

If using environment variables for credentials:

```bash
pip install python-dotenv
```

---

## 🔐 Security

Never hard-code your Instagram username or password directly inside the Python source code.

Use environment variables instead:

```env
INSTAGRAM_USERNAME=your_username
INSTAGRAM_PASSWORD=your_password
```

Also, never upload your `.env` file to GitHub.

Add it to `.gitignore`:

```text
.env
```

## 🧠 What I Learned

Through this project, I learned how Selenium can control a real web browser and perform actions just like a human user.

I also learned that modern websites use dynamically loaded content, so automation scripts need reliable element locating strategies and explicit waits.

Using `WebDriverWait` makes Selenium automation more reliable than depending entirely on `time.sleep()`.

---

## ⚠️ Responsible Use

This project is created for **educational purposes** to learn Python, Selenium, and browser automation.

Automating follows or other interactions on social-media platforms can violate platform rules and may trigger rate limits, verification challenges, or account restrictions.

The bot should therefore be tested responsibly and only where automation is permitted.
